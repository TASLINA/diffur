# Диффур — решатель дифференциальных уравнений

Веб-приложение для символьного и численного решения обыкновенных дифференциальных
уравнений первого и второго порядка. Всё считается в браузере: Python-пакеты
SymPy и SciPy работают через Pyodide в отдельном Web Worker, поэтому интерфейс не
зависает во время вычислений.

## Возможности

- символьное решение через `SymPy.dsolve` и проверка подстановкой;
- численное интегрирование через `SciPy.solve_ivp` (RK45, DOP853, Radau, BDF, LSODA);
- неявная запись уравнения, если оно линейно по старшей производной
  (`y'' + 4y = 0`, `dy/dx = x - y`);
- график решения, поле направлений и фазовый портрет для уравнений второго порядка;
- наведение с координатами, масштабирование колесом, панорамирование, сброс вида;
- экспорт графика в SVG и данных в CSV;
- история задач, тёмная/светлая тема, ссылка на задачу с параметрами;
- запасной JS-решатель RK4, если Pyodide/CDN недоступны;
- русскоязычный интерфейс с подсказками и понятными ошибками.

## Быстрый запуск

Проект статический: сборка и Node.js не нужны. Но открывать `index.html` двойным
щелчком нельзя — браузер блокирует ES-модули и `fetch` для `file://`. Запустите
любой локальный HTTP-сервер.

Windows (в PowerShell, из папки проекта):

```powershell
py -m http.server 8080
```

Затем откройте <http://localhost:8080>.

macOS/Linux:

```bash
python3 -m http.server 8080
```

При первом запуске браузер скачает Pyodide, SymPy и SciPy — примерно 30 МБ.
Это может занять до минуты. Повторные запуски используют кеш браузера, но для
первой загрузки и работы CDN нужен интернет.

## Деплой на GitHub Pages

1. Создайте репозиторий и загрузите туда файлы проекта.
2. В GitHub откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**,
   ветку `main` и каталог `/ (root)`.
4. Сохраните настройки и дождитесь публикации.

Сборка не требуется: все пути в проекте относительные, поэтому сайт работает и
в подкаталоге вида `https://username.github.io/repository/`. Файл `.nojekyll`
отключает обработку Jekyll и сохраняет статическую структуру как есть.

Подойдёт и любой другой статический хостинг: Netlify, Cloudflare Pages, Vercel
(static), Surge и т. п.

## Архитектура

```
index.html
assets/
  app.js                  логика интерфейса, сценарий решения, история, экспорт
  styles.css              оформление, темы, адаптивность
  lib/
    parser.js             разбор уравнения, проверка, генерация SymPy-кода и TeX
    solver-worker.js      Web Worker: загрузка Pyodide и запуск Python-ядра
    solver-client.js      клиент Worker'а: таймауты, прогресс, перезапуск
    solver_core.py        SymPy/SciPy-ядро (выполняется в Pyodide)
    numeric.js            резервный RK4 и поле направлений на чистом JS
    plot.js               SVG-график: зум, панорама, наведение, экспорт
    examples.js           готовые примеры
tools/
  test_solver.py          локальные тесты Python-ядра
```

### Как решается задача

1. `parser.js` нормализует запись, находит производную, проверяет переменные и
   функции, при необходимости разрешает уравнение относительно старшей
   производной и строит выражения для SymPy и численного решателя.
2. `solver-worker.js` один раз загружает Pyodide и пакеты `sympy` и `scipy`,
   затем выполняет `solver_core.py`.
3. `solver_core.py` вызывает `dsolve(..., simplify=False)`, применяет начальные
   условия, проверяет решение через `checkodesol`, строит численное решение
   `solve_ivp` и возвращает строго валидный JSON.
4. `app.js` показывает формулу через KaTeX, статистику, предупреждения и график.
5. Если движок не загрузился или упал, включается резервный RK4 на JavaScript.

## Ограничения

- Поддерживаются уравнения не выше второго порядка.
- Уравнение должно быть линейным по старшей производной, чтобы его можно было
  привести к явному виду; нелинейные по `y'`/`y''` уравнения отклоняются с
  подсказкой.
- SymPy не всегда находит решение в элементарных функциях. В этом случае
  показывается численное решение.
- Если решение имеет особенность (например, `y' = y²` при `x = 1`), численное
  интегрирование останавливается раньше конца интервала; приложение сообщает
  об этом.
- Графики строятся по вещественным значениям. Неявные решения с ветвлением
  могут отображаться в виде соотношения, а не одной явной формулы.
- Первая загрузка Pyodide требует интернета. Полностью офлайн-режима нет.
- Для уравнений второго порядка нужны `y(x₀)` и `y′(x₀)`.

## Тесты

Локальные тесты ядра (нужны Python и пакеты `sympy`, `scipy`, `numpy`):

```powershell
py tools/test_solver.py
```

Тесты прогоняют линейное уравнение, осциллятор, логистическое уравнение,
разделяющееся уравнение, `y' = sin(y)`, уравнение без элементарного решения,
особенность в `x = 0` и разрыв решения.

## Приватность

Вычисления выполняются в браузере. Введённые уравнения и параметры никуда не
отправляются. Параметры задачи сохраняются в адресе страницы и в `localStorage`
(история и тема) только на вашем устройстве.
